# India Tech Career Intelligence 2026

## Project Overview
This project analyzes the Indian technology job market using Exploratory Data Analysis (EDA).

## Objectives
- Analyze job roles and employment types.
- Identify in-demand technical skills.
- Explore companies and job locations.
- Analyze salary ranges and internship stipends.
- Understand experience and education requirements.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Team
Five-member hackathon team.
